# my-home-assistant-apps

Welcome to the **my-home-assistant-apps** repository! This repository contains custom apps, scripts, and utilities designed to extend Home Assistant.

---

## 📁 Repository Contents

* `location_tracker/`
* `personalized_info/`
* `svg_maker/`
* `repository.yaml`
* `README.md`

---

## 🚀 Included Applications & Tools

1. 📍 **Location Tracker** (`/location_tracker`)
   * **Description:** A custom module or script dedicated to location processing, tracking devices, geofencing, or managing custom location data within Home Assistant.

2. 👤 **Personalized Info** (`/personalized_info`)
   * **Description:** Designed to pull, format, and display personalized contextual data—such as user-specific routines, reminders, custom states, or tailored information cards on your Home Assistant dashboard.

3. 🎨 **SVG Maker** (`/svg_maker`)
   * **Description:** A helper tool or script used to dynamically generate, customize, or modify SVG icons and graphics for custom floorplans, dashboards, or interface elements.

---

## 🛠️ Installation in Home Assistant

1. Open **Home Assistant**.
2. Go to **Settings** -> **Add-ons** -> **Add-on Store**.
3. Click the three dots in the upper right corner and select **Repositories**.
4. Add the URL of this repository:
   ```text
   [https://github.com/jonathangibson98/my-home-assistant-apps](https://github.com/jonathangibson98/my-home-assistant-apps)
