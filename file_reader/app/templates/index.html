    Send updates from automations 
    MQTT (no token needed)
  topic:   file_reader/append/folder/log.txt
  payload: the text to add as a new line

  topic:   file_reader/overwrite/folder/log.txt
  payload: the text that replaces the file

  topic:   file_reader/write
  payload: {"file": "folder/log.txt", "text": "hello", "mode": "append"}

Don't tick "retain" on these messages.

REST (needs api_token): POST http://127.0.0.1:8100/api/file/folder/log.txt
Header:  Authorization: Bearer YOUR_TOKEN
Body:    {"text": "hello", "mode": "append"}   (or "overwrite")

Folders are created automatically. More examples are in the Documentation tab.
